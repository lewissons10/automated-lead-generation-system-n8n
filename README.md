# Automated Lead Generation System using n8n

## Overview
An automated lead generation workflow built using n8n to identify, process, enrich, and store potential business leads for Form Director.

The system automates lead research by collecting company data, extracting domains, finding contact details, scoring leads, and saving qualified leads into Google Sheets.

---

## Features
- Automated lead collection
- Company domain extraction
- Email enrichment using Hunter.io
- Lead scoring and filtering
- Google Sheets integration
- API-based workflow automation
- Real-time lead processing
- Scalable workflow design

---

## Technologies Used
- n8n
- Hunter.io API
- Google Sheets API
- HTTP Request Nodes
- JavaScript
- JSON Processing

---

## Workflow Steps
1. Generate search queries
2. Fetch lead data
3. Clean and structure data
4. Extract company domains
5. Enrich leads with emails
6. Score leads
7. Filter valid leads
8. Save final data into Google Sheets

---

## Sample Data Captured
- Company Name
- Website
- Domain
- Industry
- Location
- Company Email
- Lead Score
- Lead Quality
